# CyberNox Recon Tool 🚀

An automated, high-speed Python tool for target reconnaissance, port scanning, and directory fuzzing.

## 🛠️ Features
- **Target IP Resolution:** Quickly resolves the target domain into its IP address.
- **Port Scanning:** Scans common and open ports to identify running services.
- **Security Headers Check:** Analyzes website security headers to detect missing configurations or vulnerabilities.

---

## ⚙️ Installation Guide

Copy and run these commands one by one in your terminal:

1. Clone the repository:
```bash
git clone https://github.com/vinit-cyber-lab/cyber-recon.git
```

2. Navigate to directory:
```bash
cd cyber-recon
```

3. Create virtual environment:
```bash
python3 -m venv venv
```

4. Activate virtual environment:
```bash
source venv/bin/activate
```

5. Install dependencies:
```bash
pip install -r requirements.txt
```

---

## 🚀 How to Run

Run the tool against a target website:

```bash
python recon.py -t example.com
```
