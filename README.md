# CyberNox Recon Tool 🚀

An automated, high-speed Python tool for target reconnaissance, port scanning, and directory fuzzing.

## 🛠️ Installation & Setup

```bash
# Clone the repository
git clone [https://github.com/vinit-cyber-lab/cyber-recon.git](https://github.com/vinit-cyber-lab/cyber-recon.git)

# Navigate to directory
cd cyber-recon

# Setup virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
